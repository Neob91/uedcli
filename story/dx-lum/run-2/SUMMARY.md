# DX_LUM story exploration — RUN 2 summary

A wider second round: **nine** writers (1 fable, 4 opus, 4 sonnet) each developed the DX_LUM bible on a
fresh angle, told to avoid run 1's signature twists; then **eight** analysts (4 opus, 4 sonnet) read
all nine and ranked the strongest twists. Raw material: `raw-stories/` (9 stories), `findings/` (8
analyses). Run 1 is one level up in `../run-1/`; shared canon brief is `../SEED-BRIEF.md`.

All nine keep canon intact and honor the player-verb limits (converse / infolink / kill-incapacitate /
multitool doors / read computers).

## Consensus top twists (by analyst votes)

Votes = how many of the 8 analysts placed it in their top 3.

1. **"The Caretaker Clause" — Story 07. 7/8 — the broadest consensus of either run.**
   Ryker wasn't sent to investigate and come home; "investigator" is cover for a one-way *caretaker*
   posting the FMA reserves for universes it has already condemned. The broken liaison Ryker is meant
   to pity is his own **decommissioned predecessor**, and the same seal-and-abandon doctrine is what
   created the universe that struck back. Praised across every lens (originality, craft, immersive-sim,
   character, adversarial): it weaponizes the blank-slate avatar's disposability, it's planted through
   a coded mission designator and a handler's off-register warmth rather than exposition, and — key —
   it makes the "Ryker is the payload" idea *cause* the plot instead of just reframing it. Mirrors
   canon's stranded liaison directly.

2. **"The First Sky" — Story 09 (fable). 5/8 — the deepest concept.**
   The reactors don't burn energy; they burn **possibility** ("Lume"). Drained worlds don't go dark,
   they go *deterministic* — free will as the literal stolen resource. And U-7134 is the **Root** world
   every other victim universe budded from, so it is cannibalizing its own descendants; the FMA keeps
   an 80-year deathwatch ready to prune it. Rated the most original concept in either run and judged to
   "out-depth" run 1's twin-donor twist. Reframes the entire canon while staying investigable through
   ordinary player verbs (a flagged medical scan, a doubled photo, untranslatable android audio, cult
   liturgy that only coheres in one archive).

3. **"Good Help" — Story 01. 4/8.**
   Two interlocking twists on one surveillance conceit: the hunted operative hides as an invisible
   household **Custodian android**, waved through every checkpoint; and the ignored servant caste —
   recording their owners "for peace of mind" — is the only witness to a murdered universe. Called a
   reveal that "reprograms how you read every ambient NPC," entirely within the verbs, and set up
   fairly (a child hands the player the answer four missions early in one plain line).

Also cited: **02 The Continuity Mandate** (the one wholly-new *political* spine run 1 never attempted —
a coup that needs no multiverse secret), **05 The Ebb Tide** (the cascade-as-lifeboat trolley problem
the player mechanically understands), **08 The Threshold Communion** (the believers turn out to be
right; faith weaponized by power).

## How run 2 relates to run 1

The comparison analyst (`findings/twists-opus-4-vs-run1.md`) found run 2 largely **surpasses or
extends** run 1 rather than duplicating it:
- **07 causes what run 1 only reframed.** Run 1's best twist (Ryker is the FMA's harvested product)
  was a static reveal; 07's Caretaker Clause makes Ryker's disposability the *engine* of the plot and
  ties it to canon's stranded liaison.
- **09 out-depths run 1's cosmic mechanism.** "Steal possibility from your own descendant worlds"
  is a stranger, larger idea than run 1's "drain your near-twin."
- **02 is genuinely new ground** — a pure corporate-political spine neither run 1 nor the other run-2
  stories attempt.

## The strongest spine (fusion)

The synthesis analyst (`findings/twists-opus-3.md`) converges with others on **07 + 09 as the spine,
with 01 as the investigative texture**: the FMA's seal-and-abandon caretaker doctrine (07) is the
human/institutional layer; the Root-world possibility-siphon (09) is the cosmic truth it's covering;
the android archive (01) is how a player actually uncovers both within the verbs. Run 1's liaison and
"FMA hidden agenda" threads slot cleanly underneath.
