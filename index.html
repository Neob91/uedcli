Marble wall panels, tile flooring, ceiling fixtures — distinct materials on every surface.

# add — build geometry, pipe it into the level
$ uedcli brush build cube --texture NewYorkCity.Metal.NYC_GrayMetal_A
--width 256 --breadth 256 --height 384 --at -6144,-7840,2304
| uedcli actor add -
​
# delete — query a set, mutate it in one line
$ uedcli actor find --subclass-of Engine.Pawn
| uedcli actor delete -
​
# clip — read it back out, cut it at an angle, write it back
$ uedcli actor show Brush41
| uedcli brush clip - --plane 0,0,128 1,0,1 --keep below
| uedcli brush replace Brush41 -

Storage

One directory per actor, two plain-text files each: position and properties in actor.t3d, CSG order in order_value. It's git-tracked, like code.

actor bbox
Computes bounding box, size, and center over a set of actors. The measurement needed to place new geometry against what's already there.
brush measure relation
Reports face-by-face plane, distance, and overlap as structured data, easier and more precise for an agent to process than a screenshot.
actor diagram
A wireframe or textured schematic from any angle — read by the agent to check layout, or by a human to review it.
level photo
An in-engine render from any camera pose — the agent checks its own work with it, and a human can just as easily look at the same shot.

Inspection

An agent doesn't need to parse raw T3D to answer "what's here" or "how big is it." These commands answer directly.

actor find
Query actors by class, label, folder, or bounding box — the result pipes into any other command.
brush clip --plane
Cuts a brush along an arbitrary plane, at any angle.
actor diagram
Renders a wireframe or textured schematic of any actor set, from any angle.
level photo
In-engine render from any camera pose — a fast native draft or a full lit build.
actor bbox
Bounding box, size, and center over a set of actors.
prefab apply
Merges a saved prefab into the current level.
event graph
Traces which Tag triggers which Event across the level.
class list
Browses the engine's class hierarchy and property schema from the terminal.
texture search
Searches and previews the texture catalog.
docs search
Searches and reads the tool's reference docs.
