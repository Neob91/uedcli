# level reimport — reimport a hand-edited .dx/.unr into an existing trunk

New verb: fold a hand-edited `.dx`/`.unr` back into the trunk that produced it, matching actors by
name instead of `level import`'s wholesale `--overwrite`. Owner-approved design brainstormed and
committed at `docs/superpowers/specs/2026-08-29-level-reimport-design.md`; `spec.md` here mirrors it
for the board runbook. See `spec.md` for the full design.
