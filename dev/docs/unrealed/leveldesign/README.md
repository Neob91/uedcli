# UnrealEd / Deus Ex level-design reference — see [`kb/`](kb/README.md)

The dev-side level-design knowledge base is the **[`kb/`](kb/README.md)** tree — a 16-file,
binary-fact-checked reference: geometry & BSP, zoning/performance, lighting, textures, movers, the
actor/collision/pathing layer, the DX class catalog, gameplay-wiring & particle actors, NPC AI, human
scale, design craft & the immersive-sim philosophy, plus the asset-pipeline / editor-GUI depth. **Start
at [`kb/README.md`](kb/README.md).**

The **curated user cut** (for uedctl *users*, not internal dev) lives outside `dev/` at
[`docs/leveldesign/`](../../../../docs/leveldesign/) — topic guides + step-by-step recipes, split
`general/` (engine-generic) and `deusex/` (Deus Ex-specific).

> **History.** The older hand-written craft guides that used to live here — `csg-and-bsp.md`,
> `lighting.md`, `movers.md`, `textures-and-surfaces.md`, `zoning-occlusion-performance.md`, and the
> one-page cheat sheet — were **retired 2026-07-20**. They were a less-complete, community-sourced
> distillation; their content (fact-checked against the shipped binaries) now lives in `kb/`, and the
> reader-facing quick reference is the user cut above. Git history preserves the originals.
